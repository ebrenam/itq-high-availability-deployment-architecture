# Unidad 0: Nivelación y preparación para la asignatura

## Propósito

Esta unidad funciona como puerta de entrada al curso. Su objetivo es confirmar que el estudiante cuenta con los prerrequisitos técnicos mínimos para abordar microservicios, Kubernetes, despliegue continuo y observabilidad sin que la materia se convierta en una nivelación improvisada.

## Alcance

- Verificación de prerrequisitos técnicos en Java, Maven, Docker, Linux, redes y Git.
- Diagnóstico rápido del perfil de ingreso.
- Alineación de expectativas sobre herramientas, ritmo y tipo de trabajo práctico.

## Contenido disponible

- `clase-0-1.md`: prerrequisitos técnicos y checklist de entrada.
- `clase-0-2.md`: evaluación diagnóstica y mapa de conocimientos previos.
- `clase-0-3.md`: guía acelerada de nivelación para estudiantes con brechas puntuales.

## Resultado esperado

Al terminar esta unidad, el estudiante debe ser capaz de:

- compilar y ejecutar un proyecto Java con Maven,
- construir y ejecutar una imagen Docker básica,
- usar Git para navegar entre ramas o puntos de partida del curso,
- interpretar peticiones HTTP y revisar logs desde terminal,
- reconocer si necesita nivelación adicional antes de iniciar la Unidad 1.

## Conexión con la Unidad 1

La Unidad 1 asume que estos fundamentos ya están cubiertos. Si un estudiante no supera esta fase de entrada, tendrá dificultades para seguir el ritmo de arquitectura, orquestación y operación planteado en las siguientes unidades.
